# Mission LLB 1

A responsive legal education platform landing page built with Next.js.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

- Responsive marketing website
- Subject browser with interactive subject selection
- Feature and learning-method sections
- Membership plan preview
- FAQ accordion

## Before accepting paid memberships

Connect secure authentication, a database, payment processing, subscription entitlements, privacy policy, terms, and support workflows. The current pricing section is a preview only; no payments or student accounts are active.
